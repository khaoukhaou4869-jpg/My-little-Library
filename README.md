# My-little-Library

A minimalist static blog for sharing book reviews, reading notes, and favorite titles. This project is a small front-end website built with plain HTML, CSS, and JavaScript, designed to feel clean, modern, and easy to browse.

This repository includes a home page with a bookshelf layout, an about page, and multiple article pages for individual book reviews.

## Overview

My-little-Library is a simple personal library/blog where readers can explore a curated list of books and read short reviews. It is built as a lightweight web project with no framework, no backend, and no dependency installation required.

The project is ideal for:
- learning front-end web development
- building a small portfolio website
- creating a digital reading journal or mini blog
- showcasing book reviews in a clean layout

## How to Run

### Option 1: Open directly in a browser

Simply open the `My little Library.html` file in your browser.

### Option 2: Run a local server

From the project folder, run:

```bash
python -m http.server 8000
```

Then open:

```bash
http://localhost:8000/My%20little%20Library.html
```

My-little-Library is a small reading blog that brings together a collection of literary and personal-development books. The home page presents the books as a library shelf, and each title links to a dedicated review page.
